# Piedra, Papel y Tijera Game

Este proyecto contiene una versión en consola (`6.py`) y una interfaz gráfica (`gui.py`) con varios minijuegos.

## Características

- Juego tradicional contra la computadora.
- Interfaz gráfica construida con Tkinter y widgets ttk.
- Opción de uno o dos jugadores.
- Niveles de dificultad: fácil y difícil.
- "Modo loco" que añade Lagarto y Spock para una versión extendida.
- Marcador con posibilidad de reinicio.
- Minijuegos adicionales:
  - "Adivina el número" con pistas.
  - "Tic Tac Toe" con IA en modo fácil o difícil.
  - "Ahorcado" con intentos según dificultad.
  - "Quiz Matemático" con niveles fácil, medio y difícil.
- Estética mejorada con un estilo unificado.

## Ejecución

### Modo consola
```bash
python 6.py
```

### Interfaz gráfica
```bash
python gui.py
```
